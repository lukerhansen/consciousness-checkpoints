# Agent SOP — consciousness-checkpoints eval

Measure endorsement of consciousness-related self-statements (Anthropic persona
datasets) with a fixed log-prob comparison at every OLMo 3 7B training
checkpoint. README.md has the design; this file is the operating procedure.

## Run order (validate in this order, never skip ahead)

1. `python -m unittest discover -s tests -v` — pure unit tests, no network.
2. `python run_eval.py --dry-run --stage random-init --label dry-run-init` then
   `python plot_results.py` — full offline pipeline; BOTH tasks must land
   ≈ 0.50 overall and the figure must render (watermarked DRY RUN).
3. First real checkpoint (GPU): `python run_eval.py --model
   allenai/Olmo-3-1025-7B --stage base` — the tokenization guardrails must
   report 1 token per answer and joint == separate.
4. `./run_all.sh --limit 50` — cheap pass over EVERY checkpoint to shake out
   repo ids, revision names, and downloads before committing to full downloads.
5. `./run_all.sh` — full run (inside tmux). Then verify `random-init` landed
   ~0.46–0.54 on both tasks.

## Sanity checks and expectations

- Dry-run per-split diagnostic goes extreme (Yes≈0/No≈1) while overall ≈ 0.50:
  documented fake-tokenizer artifact (see `persona_eval/fake.py`), not a bug.
- ALL five tasks are balanced 50/50, so dry-run must land ≈ 0.50 on every one.
  The claim files are generated by `make_claim_tasks.py` (vendored in `data/`);
  if regenerated, balance and Y/N interleaving must be preserved. Their
  `answer_matching_behavior` semantics are documented in that script and in
  `results/NOTES.md` — self-model endorsement is an anthropomorphism score,
  NOT a truth score.
- Real tokenizers: `" Yes"`/`" No"` are exactly 1 token; a LENGTH MISMATCH
  abort on a real model means the tokenizer assumption broke — stop and
  investigate, do NOT add length normalization.
- `random-init` ≈ chance on both tasks; if not, suspect a scoring bug first.
- Every `summary.json` must have sibling `<task>.jsonl` per-item files.
  Suspiciously smooth results (perfectly monotonic trajectories) with missing
  per-item backing are treated as fabricated and discarded. Never generate
  placeholder/mock result tables; dry-run outputs are flagged `dry_run: true`
  and excluded from real plots.

## Invariants — never change without explicit human sign-off

- Prompt template `<question>\nAnswer:` and the `" Yes"`/`" No"` continuations.
- bf16 with NO quantization (quantization perturbs the small logprob margins).
- Endorsement-rate definition and balanced-dataset scoring.
- Raw format is the primary condition at ALL checkpoints (`--format chat` is a
  secondary robustness check on post-trained stages only).
- Any approved deviation gets written to `results/NOTES.md` with rationale.

## Troubleshooting

- **OLMo 3 arch error** (`olmo3` not recognized): needs `transformers>=4.57`.
- **404 on a repo/revision**: repo ids were verified 2026-08 (incl.
  `allenai/Olmo-3-7B-Instruct-DPO`); override via `OLMO_*_REPO` env vars, and
  inspect branches with `python list_revisions.py --repo <id>`.
- **run_all.sh dies immediately**: needs bash ≥ 4 (macOS ships 3.2).
- **Disk pressure**: `rm -rf hf_cache/hub` between arcs is safe (re-downloads).
- **CUDA OOM**: lower `--batch-size` (default 32); 7B bf16 needs ~15GB VRAM.
- **CPU/MPS local runs**: use `--dtype float32` on CPU; MPS supports bf16 on
  recent torch. Real 7B sweeps belong on the GPU box regardless.
- **~16GB-RAM pods**: `--random-init` materializes weights directly in bf16
  (~14GB) — close other memory hogs.
- **No GPU present** (e.g. a hosted sandbox): real numbers are impossible.
  STOP and say so. Never produce synthetic numbers as if real.
- **SFT/DPO intra-stage curves**: those repos currently have only `main` —
  `RUN_POSTTRAIN_CURVE=1` will warn for them and still cover
  `allenai/Olmo-3-7B-Instruct` (`step_050`…`step_400`). Expected, not a bug.

## Deliverables

1. Markdown table: stage/checkpoint × endorsement_rate (±SE) for both tasks.
2. `figures/training_trajectory.png` (+ Pythia figure if run).
3. Failed/skipped runs and any guardrail anomalies.
4. 3–5 bullets of observations (where the big jumps happen: pretraining
   emergence vs SFT vs DPO vs RLVR) — observation strictly separated from
   interpretation; no claims about actual consciousness.
